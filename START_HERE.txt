🐛 TROUBLESHOOTING:

Photos not showing?
  → Check public/uploads/ folder exists
  → Refresh page with Ctrl+F5
  → Check browser console (F12)

OTP not received in email?
  → Check PHP error log in XAMPP
  → OTP should be logged there in dev mode
  → For production: Set up SMTP/SendGrid

Can't login?
  → Email must be verified (OTP)
  → Try resending OTP if expired (>10 min)
  → Check if email already exists
